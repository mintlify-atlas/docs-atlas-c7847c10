This page documents every class and record in the `com.AnthonyChuan.Conversor` package, including constructors, methods, parameters, and return types.

<AccordionGroup>

  <Accordion title="ConversorDAO" icon="database">

    **Package:** `com.AnthonyChuan.Conversor.DAO`

    A Java record that holds the raw API response data from ExchangeRate-API. Because it is a record, all fields are immutable and accessor methods are generated automatically.

    ```java ConversorDAO.java
    public record ConversorDAO(String base_code, String target_code, double conversion_rate) {}
    ```

    **Record fields**

    <ResponseField name="base_code" type="String" required>
      The ISO 4217 currency code for the source currency (e.g., `"USD"`).
    </ResponseField>

    <ResponseField name="target_code" type="String" required>
      The ISO 4217 currency code for the target currency (e.g., `"PEN"`).
    </ResponseField>

    <ResponseField name="conversion_rate" type="double" required>
      The exchange rate from `base_code` to `target_code` at the time of the API call.
    </ResponseField>

    **Accessor methods**

    All three accessors are implicitly generated by the record declaration and explicitly overridden for clarity:

    | Method | Return type | Description |
    | --- | --- | --- |
    | `base_code()` | `String` | Returns the source currency code. |
    | `target_code()` | `String` | Returns the target currency code. |
    | `conversion_rate()` | `double` | Returns the numeric exchange rate. |

    <Note>
      `ConversorDAO` is used as the Gson deserialization target. The field names must match the keys returned by the ExchangeRate-API JSON response exactly.
    </Note>

  </Accordion>

  <Accordion title="ConvertirMonedas" icon="globe">

    **Package:** `com.AnthonyChuan.Conversor.Metodos`

    Responsible for making HTTP requests to the ExchangeRate-API v6 endpoint and deserializing the JSON response into a `ConversorDAO` record.

    ```java ConvertirMonedas.java
    public class ConvertirMonedas {
        public ConversorDAO valorConversion(String moneda1, String moneda2) {
            URI url = URI.create(
                "https://v6.exchangerate-api.com/v6/YOUR_API_KEY/pair/" + moneda1 + "/" + moneda2
            );
            HttpClient client = HttpClient.newHttpClient();
            HttpRequest request = HttpRequest.newBuilder().uri(url).build();
            try {
                HttpResponse<String> response =
                    client.send(request, HttpResponse.BodyHandlers.ofString());
                return new Gson().fromJson(response.body(), ConversorDAO.class);
            } catch (Exception e) {
                e.printStackTrace();
                throw new RuntimeException("Moneda no hallada");
            }
        }
    }
    ```

    **Constructor**

    `ConvertirMonedas()` — Default no-arg constructor. No parameters.

    **Methods**

    `valorConversion(String moneda1, String moneda2): ConversorDAO`

    Builds the API URL from the two currency codes, sends a blocking HTTP GET request, and returns the deserialized response.

    <ParamField path="body.moneda1" type="string" required>
      ISO 4217 source currency code (e.g., `"USD"`). This value is appended directly into the API URL path.
    </ParamField>

    <ParamField path="body.moneda2" type="string" required>
      ISO 4217 target currency code (e.g., `"ARS"`). This value is appended directly into the API URL path.
    </ParamField>

    **Returns:** `ConversorDAO` — A record populated from the JSON response body.

    **Throws:** `RuntimeException` with the message `"Moneda no hallada"` if the HTTP request fails or an exception is thrown during deserialization.

  </Accordion>

  <Accordion title="Decisiones" icon="list">

    **Package:** `com.AnthonyChuan.Conversor.Metodos`

    Handles menu display and user-input translation. It maps numeric shortcut inputs (`"1"`–`"4"`) to their corresponding ISO 4217 currency codes, and prints the currency selection menu to stdout.

    **Constructor**

    `Decisiones()` — Default no-arg constructor. No parameters.

    **Methods**

    ---

    `moneda1(String mon1): String`

    Translates a numeric menu shortcut into a currency code for the source currency. If the input is not a recognized shortcut, it is returned unchanged, allowing freeform ISO codes.

    <ParamField path="body.mon1" type="string" required>
      A menu shortcut (`"1"` through `"4"`) or a raw ISO 4217 code entered by the user.
    </ParamField>

    **Returns:** `String` — The resolved ISO 4217 currency code.

    | Input | Resolved code |
    | --- | --- |
    | `"1"` | `"USD"` |
    | `"2"` | `"PEN"` |
    | `"3"` | `"ARS"` |
    | `"4"` | `"COP"` |
    | anything else | returned as-is |

    ---

    `moneda2(String mon2): String`

    Identical mapping logic to `moneda1`, applied to the target currency.

    <ParamField path="body.mon2" type="string" required>
      A menu shortcut (`"1"` through `"4"`) or a raw ISO 4217 code entered by the user.
    </ParamField>

    **Returns:** `String` — The resolved ISO 4217 currency code. Same mapping table as `moneda1`.

    ---

    `imprimirMenu(): void`

    Prints the currency selection menu to stdout. No parameters, no return value.

    ```java Example output
    ******************************************************************************
        Menu de monedas
    1- USD(Dolares Americanos)
    2- PEN(Soles peruanos)
    3- ARS(Pesos Argentinos)
    4- COP(Pesos Colombianos)
    Si no encuentras la moneda que quieres cambiar ingresala bajo el mismo formato
    ******************************************************************************
    ```

    ---

    `ingreseValorACambiar(): void`

    Prints the prompt `"Ingrese el valor que desea cambiar"` to stdout. No parameters, no return value.

  </Accordion>

  <Accordion title="Conversor" icon="arrow-right-left">

    **Package:** `com.AnthonyChuan.Conversor.Modelos`

    A model class that wraps a `ConversorDAO` record and exposes the conversion calculation. It separates the raw API data object from the application-level model used during the conversion workflow.

    **Constructors**

    `Conversor()`

    Default no-arg constructor. Creates an instance with all fields set to `null`. Useful when you intend to populate the object later.

    ---

    `Conversor(ConversorDAO conversorDAO)`

    Populates `moneda1`, `moneda2`, and `valorCambio` from the provided `ConversorDAO` record.

    <ParamField path="body.conversorDAO" type="ConversorDAO" required>
      The deserialized API response record. Its `base_code()`, `target_code()`, and `conversion_rate()` accessors are called to initialize the model fields.
    </ParamField>

    ```java Constructing from an API response
    ConversorDAO conversorDAO = convertirMonedas.valorConversion("USD", "PEN");
    Conversor conversor = new Conversor(conversorDAO);
    ```

    **Methods**

    | Method | Return type | Description |
    | --- | --- | --- |
    | `getMoneda1()` | `String` | Returns the source currency code. |
    | `getMoneda2()` | `String` | Returns the target currency code. |
    | `getValorCambio()` | `Double` | Returns the exchange rate. |
    | `calculo(double valorCambiar)` | `Double` | Multiplies `valorCambiar` by the stored exchange rate and returns the converted amount. |
    | `toString()` | `String` | Returns a human-readable representation of the object. |

    ---

    `calculo(double valorCambiar): Double`

    Performs the currency conversion calculation.

    <ParamField path="body.valorCambiar" type="double" required>
      The amount in the source currency to convert.
    </ParamField>

    **Returns:** `Double` — The equivalent amount in the target currency.

    ```java Example
    Conversor conversor = new Conversor(conversorDAO); // USD -> PEN, rate = 3.72
    Double result = conversor.calculo(100);             // returns 372.0
    ```

    ---

    `toString(): String`

    **Returns:** `String` — Format: `Conversor{moneda1='USD', moneda2='PEN', valorCambio=3.72}`

  </Accordion>
