The Currency Converter with API is a Java 17 console application that converts monetary amounts between currencies in real time. It calls the [ExchangeRate-API](https://www.exchangerate-api.com/) to fetch live exchange rates, applies the rate to an amount you provide, and prints the converted result.

## Supported currencies

The interactive menu exposes four currencies by number:

| Number | Code | Currency             |
| ------ | ---- | -------------------- |
| 1      | USD  | US Dollar            |
| 2      | PEN  | Peruvian Sol         |
| 3      | ARS  | Argentine Peso       |
| 4      | COP  | Colombian Peso       |

You are not limited to these four. At either currency prompt you can type any valid [ISO 4217](https://en.wikipedia.org/wiki/ISO_4217) currency code (for example `EUR`, `BRL`, or `JPY`) and the application will resolve it directly against ExchangeRate-API.

## External dependency

The application depends on **ExchangeRate-API** (`https://v6.exchangerate-api.com`) to retrieve conversion rates. You must supply a valid API key. A free-tier account provides enough requests for personal use. Sign up at [exchangerate-api.com](https://www.exchangerate-api.com/).

## Prerequisites

Before running the project you need:

- **Java 17 or later** — the project uses records and the `java.net.http` HTTP client introduced in Java 11, compiled targeting Java 17.
- **Gson 2.11.0** — the only runtime dependency. Download the JAR from the [Maven Central repository](https://search.maven.org/artifact/com.google.code.gson/gson/2.11.0/jar) and place it somewhere on your classpath when compiling and running.
- An **ExchangeRate-API key** — replace the placeholder `YOUR_API_KEY` in `ConvertirMonedas.java` with your own key.

<Note>
  The amount to convert is read as a whole integer. Decimal values are not accepted — entering `10.5` will cause an `InputMismatchException` and the program will exit with an error message.
</Note>
