---
title: Quickstart
description: Set up, compile, and run the Currency Converter with API application from scratch in five steps.
---

Follow these steps to go from zero to a working currency conversion in your terminal.

<Warning>
  The API key is hardcoded in `ConvertirMonedas.java` as the string `YOUR_API_KEY`. Before running the application, open that file and replace the placeholder with your own key from [exchangerate-api.com](https://www.exchangerate-api.com/). Requests made with the placeholder key will fail.
</Warning>

<Steps>
  <Step title="Install prerequisites">
    Confirm that Java 17 or later is available:

    ```bash
    java -version
    ```

    Download the Gson 2.11.0 JAR from Maven Central and save it to a known path, for example `lib/gson-2.11.0.jar`:

    ```bash
    mkdir lib
    curl -L -o lib/gson-2.11.0.jar \
      https://repo1.maven.org/maven2/com/google/code/gson/gson/2.11.0/gson-2.11.0.jar
    ```
  </Step>

  <Step title="Get the source code">
    Clone the repository or download and unzip the source archive:

    ```bash
    git clone https://github.com/AnthonyChuan/ConversorDeMonedasConAPI.git
    cd ConversorDeMonedasConAPI
    ```

    The relevant source files are:

    ```
    src/
    └── com/AnthonyChuan/Conversor/
        ├── main.java
        ├── DAO/
        │   └── ConversorDAO.java
        ├── Metodos/
        │   ├── ConvertirMonedas.java
        │   └── Decisiones.java
        └── Modelos/
            └── Conversor.java
    ```
  </Step>

  <Step title="Replace the API key">
    Open `src/com/AnthonyChuan/Conversor/Metodos/ConvertirMonedas.java` and find this line:

    ```java
    URI url = URI.create("https://v6.exchangerate-api.com/v6/YOUR_API_KEY/pair/" + moneda1 + "/" + moneda2);
    ```

    Replace `YOUR_API_KEY` with the key from your ExchangeRate-API account dashboard.
  </Step>

  <Step title="Compile the project">
    From the project root, compile all source files with Gson on the classpath:

    ```bash
    javac -cp lib/gson-2.11.0.jar \
      -d out \
      src/com/AnthonyChuan/Conversor/DAO/ConversorDAO.java \
      src/com/AnthonyChuan/Conversor/Modelos/Conversor.java \
      src/com/AnthonyChuan/Conversor/Metodos/ConvertirMonedas.java \
      src/com/AnthonyChuan/Conversor/Metodos/Decisiones.java \
      src/com/AnthonyChuan/Conversor/main.java
    ```

    Compiled `.class` files are written to the `out/` directory.
  </Step>

  <Step title="Run the application">
    Launch the application with both the `out/` directory and the Gson JAR on the classpath:

    ```bash
    java -cp out:lib/gson-2.11.0.jar com.AnthonyChuan.Conversor.main
    ```

    On Windows, replace the `:` classpath separator with `;`:

    ```bash
    java -cp out;lib\gson-2.11.0.jar com.AnthonyChuan.Conversor.main
    ```
  </Step>
</Steps>

## Example session

The following shows a complete interactive session converting **100 USD to ARS**:

```text
Ingrese el valor que desea cambiar
100
******************************************************************************
    Menu de monedas 
1- USD(Dolares Americanos)
2- PEN(Soles peruanos)
3- ARS(Pesos Argentinos)
4- COP(Pesos Colombianos)
Si no encuentras la moneda que quieres cambiar ingresala bajo el mismo formato
******************************************************************************
Ingrese moneda por cambiar: 
1
Ingrese moneda de cambio: 
3
Su cambio es de: 89523.0 ARS
```

The user enters `100` as the amount, selects `1` for USD as the source currency, and `3` for ARS as the target currency. The application fetches the live rate from ExchangeRate-API and prints the converted amount.

<Tip>
  Instead of choosing a menu number, you can type an ISO 4217 currency code directly at either currency prompt. For example, entering `EUR` or `JPY` works without any code changes — the application passes your input straight to the API.
</Tip>
